# 数据与证据

保留 inputs/ 原件；清洗脚本和处理结果写在其他目录，并用 run 记录输入输出。
检查维度、单位、主键、重复、缺失、异常、样本范围和数据泄漏；不要擅自删除不利样本。
预测题先冻结训练/验证/测试协议，时间序列按时间方向切分。
外部数据或文献只按需要检索，保存 URL/DOI、访问时间、支持的主张、证据位置与许可说明。
下载失败和无可用搜索工具应显式记录，不虚构来源或依赖项。

data-report.md 包含：输入清单与含义、处理方法、来源、环境/工具实际可用情况、数据限制。
没有外部数据的题说明为何不适用；合成算例标为合成，不充当观测事实。
运行 Python/求解器前探测环境；使用现有可用工具，不修改用户全局环境或索要聊天中的密钥。
