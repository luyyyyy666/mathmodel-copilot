# 基线与改进

## baseline

在 baseline.md 定义最简单有用模型的变量、单位、公式、约束和适用条件。
写实际脚本，用 run 执行并记录代码、数据、参数文件为 --input，结果为 --output。
明确基线的可行性、误差及局限。计算题不能只提交数学描述；理论题保留推导、前提和边界检查。
complete baseline 同时登记说明、代码和结果，并通过 --execution 指向本阶段实际执行。

## improve

针对基线的具体不足提出改进假设，在 model.md 先写实验计划，再运行。
比较使用相同数据/预算/指标；保留不成功实验，不按结果临时放宽阈值。
优化记录可行性、目标、求解状态与 gap；超时的可行解不称全局最优。
仿真记录种子、重复次数和不确定性；评价模型检查权重扰动和排序稳定性。
改进无效可以选择基线，说明原因。无需为满足数量而发明多个候选。

基线足够或剩余预算不适合改进时：skip --stage improve --reason "具体依据"。
其他阶段不能跳过。重新计算已有阶段前 reopen，使用新输出文件名，旧摘要和内容快照可追溯。
