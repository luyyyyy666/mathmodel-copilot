# 理解题目

读取 inputs/ 中的原件；PDF/图片中的关键公式和表格对照原件核查。
在 problem.md 记录：

- 每个小问需要支持的决策、输出形式和可检查验收条件。
- 已知数据、变量、单位、范围、约束；小问间共享参数和结论依赖。
- 假设及可能推翻它的证据；区分题目给定、用户要求和模型推断。
- 时间/计算预算，交付格式，实际比赛规则及来源。
- 基线思路、评价指标方向、验证方法和预设容差。

只为影响解法的缺失信息暂停。可以合理选定的细节记录为假设后继续。
理论题初始化使用 --kind theory，后续保存推导与反例检查，不强制生成虚假数据。

complete understand 只证明文件已登记；Agent 自行检查是否真正覆盖了所有小问。
